# Choose your Developer

Use Codex or Claude as your Developer for each logical task. Both accept the same one-paste Build Ticket
from the Deesha's Web Expert and synchronise the existing project records themselves.

## If you are using Codex

Open `CODEX-START.md`. Do not edit `CURRENT-BUILD-TASK.md` yourself.

## If you are using Claude

Open `CLAUDE-START.md`. Do not edit `CURRENT-BUILD-TASK.md` yourself.

## The Build Ticket is only three actions

1. Ask the Deesha's Web Expert for the approved `DEESHA DEVELOPER BUILD TICKET`.
2. Copy the entire block into your chosen Developer in this project folder.
3. Wait for “Hard hat on. Ticket received.” and the local preview. The
   Developer updates the existing `.md` records.

Never create or copy four governance files by hand. They are already here.

## Switching Developers

Switch only after the current task has one of these states:

- not started;
- completed, committed and pushed; or
- explicitly stopped with the changed files and unresolved checks recorded.

Before switching, ask the new Developer to read the shared state and inspect the
existing work. Never ask it to recreate a completed checkpoint.
