# Layout Menu

> Pick the layout closest to your website, by name. Tell Claude:
> **"Use Layout L2"** — then customise from there. Mixing is fine
> ("L1, but with L5's contact section").

## L1 — Classic Professional

Best for: consultants, professional services, agencies.

```
┌──────────────────────────────┐
│ Navbar                       │
│ Hero — headline + CTA        │
│ Trust band (why believe you) │
│ Services (3-column cards)    │
│ About / value proposition    │
│ Testimonials                 │
│ FAQ (accordion)              │
│ Final CTA                    │
│ Footer                       │
└──────────────────────────────┘
```

## L2 — Split Hero Consultant

Best for: personal brands — CA, lawyer, coach, freelancer with a face.

```
┌──────────────────────────────┐
│ Navbar                       │
│ Hero: text left │ photo right│
│ Credentials strip            │
│ Services (cards)             │
│ How we work (3 steps)        │
│ Testimonials                 │
│ Contact CTA + footer         │
└──────────────────────────────┘
```

## L3 — Portfolio First

Best for: designers, photographers, architects, artists — work speaks first.

```
┌──────────────────────────────┐
│ Navbar (minimal)             │
│ One-line intro               │
│ Work gallery (grid)          │
│ About (short)                │
│ Services / pricing           │
│ Contact CTA + footer         │
└──────────────────────────────┘
```

## L4 — Single-Page Lander

Best for: one product, one service, one event — one page, one goal.

```
┌──────────────────────────────┐
│ Sticky navbar + CTA          │
│ Hero — the promise           │
│ Benefits (bullets)           │
│ How it works                 │
│ Proof / examples             │
│ FAQ                          │
│ Final CTA (repeated)         │
└──────────────────────────────┘
```

## L5 — Local Business

Best for: shops, clinics, salons, restaurants, tuition centres.

```
┌──────────────────────────────┐
│ Navbar + WhatsApp button     │
│ Hero: name + hours + area    │
│ Services / menu (with prices │
│   from site-data.json)       │
│ Photo gallery                │
│ Announcement bar (editable)  │
│ Find us: address + map link  │
│ WhatsApp CTA + footer        │
└──────────────────────────────┘
```

## L6 — Coaching / Training

Best for: trainers, coaching classes, course creators.

```
┌──────────────────────────────┐
│ Navbar                       │
│ Hero: the outcome you teach  │
│ Programmes (cards + fees)    │
│ About the trainer (photo)    │
│ Student words (testimonials) │
│ FAQ                          │
│ Enrol / WhatsApp CTA         │
│ Footer                       │
└──────────────────────────────┘
```
