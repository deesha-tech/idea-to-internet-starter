# Account आणि Laptop Readiness Guide — English + मराठी

हा guide **Deesha Idea to Internet SkillLab** साठी आहे. Coding experience
आवश्यक नाही. 30–45 minutes ठेवा आणि steps क्रमाने पूर्ण करा.

> तुमचा स्वतःचा email आणि phone वापरा. Password, OTP, recovery code किंवा
> payment माहिती trainer, GPT, Claude किंवा Codex सोबत कधीही share करू नका.

## सुरुवातीला काय हवे / What you need

- Windows 10/11 किंवा macOS 12+ असलेला laptop
- Chrome किंवा modern browser
- आत्ता उघडता येणारा email inbox
- Verification साठी mobile phone
- Stable internet

## 1 — ChatGPT account तयार किंवा check करा

1. Official [ChatGPT sign-in page](https://chatgpt.com/auth/login) उघडा.
2. **Continue with Google**, **Apple**, **phone** किंवा email निवडा.
3. Screen वर आलेले email/phone verification पूर्ण करा.
4. Sign in करून new chat मध्ये `Hello` पाठवा.

✅ **Ready when / तयार केव्हा:** ChatGPT तुमच्या message ला reply देतो.

Deesha team ने सांगितल्याशिवाय नवीन subscription खरेदी करू नका.

## 2 — GitHub account तयार आणि verify करा

GitHub म्हणजे तुमच्या website files चे सुरक्षित online घर.

1. [Free GitHub account तयार करा](https://github.com/signup) ही link उघडा.
2. सोपा पर्याय: **Continue with Google**. Email सुद्धा वापरू शकता.
3. लक्षात राहील असे professional username निवडा.
4. Screen वरील verification पूर्ण करा.
5. GitHub कडून आलेला email उघडा आणि email address verify करा.
6. पुन्हा [GitHub](https://github.com/) वर sign in करा.
7. Profile picture निवडा आणि username दिसतोय का check करा.

✅ **Ready when / तयार केव्हा:** GitHub मध्ये sign in झाले आहे आणि email
verified आहे. Repository तयार करण्यासाठी verified email आवश्यक असतो.

Workshop नंतर GitHub security settings मध्ये two-factor authentication सुरू
करणे चांगले.

## 3 — GitHub वापरून Vercel account तयार करा

Vercel तुमच्या website files ची live preview link तयार करेल.

1. [Vercel sign-up](https://vercel.com/signup) उघडा.
2. **Continue with GitHub** निवडा.
3. GitHub permission विचारल्यास screen वाचा आणि Vercel authorise करा.
4. Welcome questions पूर्ण करा. Trainer ने वेगळे सांगितले नसेल तर free
   personal option निवडा.
5. [Vercel dashboard](https://vercel.com/dashboard) उघडा.

✅ **Ready when / तयार केव्हा:** Vercel dashboard उघडतो आणि GitHub identity
दिसते.

## 4 — Visual Studio Code install करा

VS Code मध्ये website files आणि AI builder एकत्र दिसतील.

1. Official [VS Code download page](https://code.visualstudio.com/download) उघडा.
2. **Windows:** तुमच्या laptop साठी **User Installer** निवडा. बहुतेक laptops
   x64 असतात. Installer उघडा आणि default options ठेवा.
3. **Mac:** chip माहीत नसेल तर **Universal .dmg** निवडा. File उघडा आणि Visual
   Studio Code ला Applications मध्ये drag करा.
4. VS Code उघडा.

✅ **Ready when / तयार केव्हा:** VS Code ची Welcome screen दिसते.

## 5 — Node.js LTS install करा

Node.js म्हणजे laptop वर website चालवणारे engine.

1. Official [Node.js download page](https://nodejs.org/en/download) उघडा.
2. **LTS** लिहिलेली version निवडा; **Current** निवडू नका.
3. Windows किंवा macOS साठी normal installer निवडा.
4. Installer उघडा आणि default options स्वीकारा.
5. Installation नंतर VS Code बंद करून पुन्हा उघडा.
6. VS Code मध्ये **Terminal → New Terminal** निवडा.
7. खालील commands एकावेळी एक चालवा:

```text
node -v
npm -v
```

✅ **Ready when / तयार केव्हा:** दोन्ही commands version number दाखवतात.
Exact version महत्त्वाची नाही. “not found” किंवा “not recognised” दिसू नये.

## 6 — एक AI builder निवडा आणि install करा

Trainer ने confirm केलेला **एकच** पर्याय install करा. दोन्ही आवश्यक नाहीत.

### Option A — Codex

1. [Codex — OpenAI’s coding agent](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt) उघडा.
2. **Install** निवडा आणि VS Code उघडण्यास allow करा.
3. VS Code मधील Codex panel उघडा आणि ChatGPT account ने sign in करा.
4. Empty folder उघडून लिहा: `Please reply: Codex is ready.`

✅ **Ready when:** Codex VS Code मध्ये reply देतो.

### Option B — Claude Code

1. [Claude Code for VS Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code) उघडा.
2. **Install** निवडा आणि VS Code उघडण्यास allow करा.
3. Claude Code panel उघडा आणि sign-in steps पूर्ण करा.
4. Empty folder उघडून लिहा: `Please reply: Claude is ready.`

✅ **Ready when:** Claude VS Code मध्ये reply देतो.

Provider कडे eligible account किंवा subscription आवश्यक असू शकते. Workshop
team ने सांगितल्याशिवाय subscription खरेदी करू नका.

## 7 — VS Code मध्ये GitHub sign-in test करा

1. VS Code च्या bottom-left जवळ **Accounts** icon निवडा.
2. दिसल्यास **Sign in with GitHub** निवडा.
3. Browser उघडल्यावर sign-in approve करा.
4. VS Code मध्ये परत या.

✅ **Ready when / तयार केव्हा:** Accounts icon खाली GitHub account दिसतो.

## 8 — Final readiness checklist / अंतिम तपासणी

- [ ] ChatGPT उघडतो आणि reply देतो
- [ ] GitHub उघडतो आणि email verified आहे
- [ ] GitHub वापरून Vercel dashboard उघडतो
- [ ] VS Code उघडतो
- [ ] `node -v` version दाखवतो
- [ ] `npm -v` version दाखवतो
- [ ] Codex **किंवा** Claude VS Code मध्ये reply देतो
- [ ] VS Code मध्ये GitHub sign-in झाले आहे
- [ ] Trainer ने दिलेली Deesha GPT link उघडते

सर्व boxes tick झाल्यास तुम्ही workshop-ready आहात. VS Code Welcome screen आणि
AI builder panel चा एक screenshot approved workshop help channel वर पाठवा.
Password किंवा private code screenshot मध्ये नसावा.

## काही चालले नाही तर / If something fails

सगळे पुन्हा install करू नका. Exact error चा photo/screenshot घ्या आणि कोणता
numbered step fail झाला ते लिहा. फक्त ही माहिती workshop support team ला पाठवा.
