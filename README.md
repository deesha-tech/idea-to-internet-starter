# My Website — Idea to Internet starter

Welcome! 🎉 This is your website's starting point, from the **Idea to
Internet** SkillLab by [Deesha](https://www.deeshatechacademy.com).

## First time here?

1. Open this folder in **VS Code**.
2. In the terminal (**Terminal → New Terminal**): `npm install`, then
   `npm run dev`.
3. Open **localhost:3000** in your browser — you should see
   **"It works! 🎉"**.
4. Click **Open my playbook** and answer its questions — your build
   prompt assembles as you go, and your answers are saved into
   `BLUEPRINT.md`.
5. Then tell Claude: **"Read my blueprint and confirm before building."**

## The three files that run the show

- `CLAUDE.md` — Claude's working agreement: it interviews, you decide.
- `BLUEPRINT.md` — your plan, written by the playbook.
- `PROGRESS.md` — how far your website has come.

Things you'll want to change later — prices, timings, announcements —
live in `content/site-data.json`. Edit a line, save, refresh.

Stuck? Your workshop WhatsApp group is the fastest help.
