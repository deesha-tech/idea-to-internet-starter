# Account and Laptop Readiness Guide — English

For the **Deesha Idea to Internet SkillLab**. No coding experience is needed.
Allow about 30–45 minutes. Complete the steps in order.

> Use your own email address and phone. Never share a password, OTP, recovery
> code or payment information with the trainer, GPT, Claude or Codex.

## What you need

- A laptop with Windows 10/11 or macOS 12 or later
- Chrome or another modern browser
- An email inbox you can open now
- Your mobile phone for verification
- Stable internet

## 1 — Create or check your ChatGPT account

1. Open the official [ChatGPT sign-in page](https://chatgpt.com/auth/login).
2. Choose **Continue with Google**, **Continue with Apple**, **Continue with
   phone**, or enter your email.
3. Complete any email or phone verification shown to you.
4. Sign in and send `Hello` in a new chat.

✅ **Ready when:** ChatGPT replies to your message.

Do not buy a new subscription unless Deesha has confirmed that you need one.

## 2 — Create and verify your GitHub account

GitHub is the safe online home for your website files.

1. Open [Create a free GitHub account](https://github.com/signup).
2. The simplest option is **Continue with Google**. You may also use email.
3. Choose a professional username that you can remember.
4. Complete the on-screen verification.
5. Open the email sent by GitHub and verify your email address.
6. Return to [GitHub](https://github.com/) and sign in.
7. Select your profile picture. Confirm that your username is visible.

✅ **Ready when:** you are signed in and your email is verified. GitHub needs a
verified email for basic work such as creating a repository.

Recommended after the workshop: enable two-factor authentication in GitHub
security settings.

## 3 — Create your Vercel account through GitHub

Vercel will turn your website files into a live preview link.

1. Open [Vercel sign-up](https://vercel.com/signup).
2. Choose **Continue with GitHub**.
3. If GitHub asks for permission, read the screen and authorise Vercel.
4. Complete the short Vercel welcome questions. Choose the free personal option
   unless the trainer instructs you differently.
5. Open the [Vercel dashboard](https://vercel.com/dashboard).

✅ **Ready when:** the Vercel dashboard opens and your GitHub identity is shown.

## 4 — Install Visual Studio Code

VS Code is the workspace where your website files and Developer will sit.

1. Open the official [VS Code download page](https://code.visualstudio.com/download).
2. **Windows:** choose **User Installer** for your computer. Most laptops use
   x64. Open the downloaded installer and keep the default options.
3. **Mac:** choose the **Universal .dmg** if you are unsure about the chip. Open
   it and drag Visual Studio Code into Applications.
4. Open VS Code.

✅ **Ready when:** VS Code opens and shows its Welcome page.

## 5 — Install Node.js LTS

Node.js is the engine that runs your website on your laptop.

1. Open the official [Node.js download page](https://nodejs.org/en/download).
2. Select the version marked **LTS**, not **Current**.
3. Choose the normal installer for Windows or macOS.
4. Open the installer and accept the default options.
5. Close and reopen VS Code after installation.
6. In VS Code select **Terminal → New Terminal**.
7. Run these commands one at a time:

```text
node -v
npm -v
```

✅ **Ready when:** both commands show version numbers. An exact version is not
important; neither command should say “not found” or “not recognised”.

## 6 — Choose and install one Developer

Install **one** option confirmed by the trainer. You do not need both.

### Option A — Codex

1. Open [Codex — OpenAI’s coding agent](https://marketplace.visualstudio.com/items?itemName=openai.chatgpt).
2. Select **Install** and allow it to open VS Code.
3. In VS Code, open the Codex panel and sign in with your ChatGPT account.
4. Open an empty folder and send: `Please reply: Codex is ready.`

✅ **Ready when:** Codex replies inside VS Code.

### Option B — Claude Code

1. Open [Claude Code for VS Code](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code).
2. Select **Install** and allow it to open VS Code.
3. Open the Claude Code panel and follow its sign-in steps.
4. Open an empty folder and send: `Please reply: Claude is ready.`

✅ **Ready when:** Claude replies inside VS Code.

Your chosen provider may require an eligible account or subscription. Do not
purchase one until the workshop team confirms the supported option.

## 7 — Test GitHub sign-in inside VS Code

1. In VS Code, select the **Accounts** icon near the bottom-left.
2. Choose **Sign in with GitHub** if it is shown.
3. Allow the browser to open and approve the sign-in.
4. Return to VS Code.

✅ **Ready when:** your GitHub account appears under the Accounts icon.

## 8 — Final readiness checklist

Tick every item:

- [ ] ChatGPT opens and replies
- [ ] GitHub opens and the email is verified
- [ ] Vercel dashboard opens through GitHub
- [ ] VS Code opens
- [ ] `node -v` shows a version
- [ ] `npm -v` shows a version
- [ ] Codex **or** Claude replies inside VS Code
- [ ] GitHub is signed in inside VS Code
- [ ] I can access the Deesha's Web Expert link supplied by the trainer

If every item is checked, you are workshop-ready. Take one screenshot of the
VS Code Welcome screen with the Developer panel open and send it through the
workshop’s approved help channel. Do not include passwords or private codes.

## If something does not work

Do not reinstall everything. Take a photo or screenshot of the exact error and
note which numbered step failed. Share only that information with the workshop
support team.
